Style bank

The values every drawing of the talk is made with: its colours, its type, its weights, its radii, how it draws absence and the head of an arrow. The source is world/style.py and world/model.py; this page only shows them. Each meaning is quoted from the code, with the line it comes from; a value whose code gives no reason says so. Who uses a value is read off the current source: the files that name it in their code, so a value reached through a function (box() drawing in INK) is credited to that function. Every specimen is drawn by the house function itself, at whole size: one pixel per unit of the 1000-unit fixed view. The things these values draw are in the concept bank.
